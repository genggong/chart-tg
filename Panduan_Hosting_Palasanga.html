Bagian 1 — Pindahkan pengirim SC ke palasanga (5 langkah, ±5 menit)

Penting dulu — token bot lama sudah bocor. Repo genggong/chart-tg ternyata publik, dan di dalamnya ada send.php berisi token bot @Kingatasolutionsbot. Siapa pun bisa memakai token itu untuk mengirim pesan ke grup/channel Anda. Wajib revoke dulu.

Langkah 1 — Revoke token bot (BotFather)

  1. Buka chat dengan @BotFather → ketik /revoke
  2. Pilih bot @Kingatasolutionsbot
  3. BotFather mengirim token baru (format 123456789:AA...) — simpan, kita pakai di Langkah 3

Langkah 2 — Buat folder endpoint di hosting

Buka DirectAdmin → Terminal (atau SSH), jalankan:

mkdir -p ~/domains/palasanga.site/public_html/tg_shot && ls -la ~/domains/palasanga.site/public_html/

Langkah 3 — Unggah send.php + tempel token baru

  1. File Manager → masuk domains/palasanga.site/public_html/tg_shot → Upload file send.php (saya kirim terpisah)
  2. Klik kanan send.php → Edit, cari baris 14: 
    const TG_BOT_TOKEN = 'TEMPEL-TOKEN-BARU-DARI-BOTFATHER';
  3. Ganti dengan token dari Langkah 1 → Save. Baris SECRET_KEY (baris 16) jangan diubah — sudah saya samakan dengan EA: 
    const SECRET_KEY = 'PAL2f01487bf0cdec19040bde';

Langkah 4 — Uji endpoint hidup

curl -s "https://palasanga.site/tg_shot/send.php?key=PAL2f01487bf0cdec19040bde"

Yang benar: balasan JSON (bukan halaman error). Kalau muncul key salah → SECRET_KEY tidak sama dengan di atas. Kalau 500 → token belum benar di baris 14.

Langkah 5 — Uji kirim foto ke grup

Bilang ke saya "endpoint siap" → saya kirim foto uji langsung dari server saya ke grup Vantera Trading Konsultan. Kalau foto muncul di grup, endpoint sudah benar 100% dan tidak perlu diapa-apakan lagi.

Bagian 2 — MT5: ChartShotSender (SC otomatis ke grup)

BerkasDitaruh di
ChartShotSender.mq5 (v1.05)MQL5\Experts\
  1. MT5 → File → Open Data Folder → buka MQL5\Experts → tempel ChartShotSender.mq5
  2. F4 (MetaEditor) → buka file itu → F7 compile → lihat tab Errors harus 0 error, 0 warning
  3. Kembali ke MT5 → Ctrl+N → Expert Advisors → seret ChartShotSender ke chart M15 yang sama dengan panel OptimusPanel
  4. Di jendela Inputs, isi (nilai ini sudah jadi default di v1.05, cek saja):
    InputNilaiArti
    everyMinutes15SC tiap 15 menit di boundary :00/:15/:30/:45
    webUrlhttps://palasanga.site/tg_shot/send.phpendpoint baru (palasanga)
    webKeyPAL2f01487bf0cdec19040bdeharus sama dengan SECRET_KEY di send.php
    webChat-1001583828319grup Vantera Trading Konsultan
    shotWidth / shotHeight1920 / 1080biar 30 kolom panel + blok RPS/Market Info tidak terpotong
    ignoreMarketClosefalseweekend tidak kirim SC (kecuali simbol crypto)
  5. Buka Tools → Options → Expert Advisors → centang Allow WebRequest for listed URL → Add: 
    https://palasanga.site/tg_shot/send.php
    Kalau langkah ini dilewat, jurnal menulis error 4060 dan SC tidak terkirim.
  6. Cek jurnal tab Experts, harus muncul: [ChartShotSender] Terkirim ke -1001583828319 (...)
